# 踩坑实录（写脚本时不知道为什么这么写，看这里）

## 2026-10-24 事故：9 篇重复 + 6 篇驳回 + 删 16 篇
- 根因：只信本地文件名后缀（`__待发布`），没拉线上清单核对。
- 规则：任何发布前先跑 `tc_list.py` / `juejin_list.py`，线上确认无同标题才发。

## 腾讯云
- 文章标签是必填，空着点「确认发布」无反应（不报错，就是没反应）。
- 发布弹窗关闭/刷新后，已填标签与关键词全部丢失，必须同一次弹窗填完。
- 标签挂法：输入框点一下 → 输入 → 停 1 秒 → 下拉候选 → 点第一个。
- 审核周期实测约 5 小时；「我的文章」登录态列表是最快确认渠道。
- 删除走回收站可恢复：卡片面板 → 「删除」→ 弹窗「确定」。

## 掘金
- 入口链：首页 add-btn → send-button（window.open 开 popup，必须 expect_page 捕获）。
- 正文用 CodeMirror：必须 focus() + keyboard.insert_text（click 会被预览浮层拦截）。
- 标签是 byte-select：placeholder 拦 pointer，正解 = 点 placeholder → keyboard.type → 点第一个 option。
- 成功判据：URL 跳 `/published`。

## 小红书
- 「上传图文」tab 必须 JS dispatch（Playwright click 报 outside viewport）。
- 发布按钮在 `<xhs-publish-btn>` 闭包 shadow DOM：PIL 找红色像素质心再 mouse.click。
- 标题 ≤ 20 字；正文 tiptap 用 click+insert_text，≤1000 字（innerText 计数虚高约 40）。
- 封面 1080x1440 文字卡片（PIL 生成）。

## 登录态
- 全平台 cookie 存 `FMJ_BASE/.publish-state/<平台>.json`。
- 失效重新扫码，不硬试；抖音风控最狠（码 2-3 分钟过期）。
